# Newbiton — 환승 막차 알리미

뉴비톤 해커톤(2026-09-12) 프로젝트. 지하철·버스 환승을 고려하고, 개인 도보속도를 반영해
"몇 시까지 출발해야 막차를 탈 수 있는지" 알려주는 서비스입니다.

## 폴더 구조

```
Newbiton/
├── docs/
│   ├── PRD_Newbiton.md      # 전체 기획 문서 (0~10장)
│   └── Newbiton_mockup.pdf  # 화면 5개 목업
├── backend/                 # Node.js + Express (본인 담당) — 실행법은 backend/README.md
└── frontend/                # React + Vite (프론트엔드 담당이 추가 예정)
```

## 시작하기

- 기획/기능 명세: `docs/PRD_Newbiton.md`
- 화면 디자인 참고: `docs/Newbiton_mockup.pdf`
- 백엔드 실행 방법: `backend/README.md`
- 프론트엔드는 담당자가 `frontend/` 폴더에 Vite 프로젝트를 새로 만듭니다.

## 팀
