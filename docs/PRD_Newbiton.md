# 1. 서비스 개요

## 1.1 문제 정의

늦은 시간 외부에 머무는 대중교통 이용자가 실제로 알고 싶은 것은 단순히 특정 지하철이나 버스의 막차 시각이 아니다.

사용자가 실제로 궁금한 것은

> **“내가 지금 있는 곳에서 몇 시까지 출발해야 집에 갈 수 있는가?”**

이다.

특히 목적지까지 여러 개의 지하철·버스를 환승해야 하는 경우 마지막 교통수단의 막차만 확인해서는 전체 경로를 완주할 수 있는지 판단하기 어렵다.

또한 출발지에서 역·정류장까지 이동하는 도보시간과 환승시간 역시 사용자의 보행 속도에 따라 달라질 수 있다.

막차를 놓친 이후에는 심야버스나 주변 대기 장소 등의 대안 역시 사용자가 다시 직접 검색해야 한다.

---

## 1.2 해결 방안

막차랑이는 사용자의

- 출발지
- 목적지
- 보행 속도
- 선택한 대중교통 경로

를 기반으로 경로에 포함된 각 지하철·버스의 막차 시각을 분석한다.

각 대중교통 구간에 대해

**해당 교통수단의 막차 시각 - 해당 교통수단 탑승 지점까지의 누적 이동시간**

을 계산하고, 그중 가장 이른 시각을 전체 경로의 **최종 출발 마감 시각(Departure Deadline)** 으로 결정한다.

이를 통해 사용자는 복잡한 계산 없이

> **“오늘 몇 시까지 여기서 출발해야 하는가”**

를 바로 확인할 수 있다.

# 2. 핵심 가치

1. 단순 막차 조회가 아닌 **출발 마감 시각 역산**
2. 경로에 포함된 **모든 대중교통 구간의 막차 고려**
3. 사용자의 보행 속도를 반영한 도보시간 계산
4. 실시간 카운트다운을 통한 즉각적인 상황 인지
5. 남은 시간에 따라 변화하는 **막차랑이 캐릭터**
6. Web Push를 이용한 막차 알림
7. 막차 실패 시 해당 위치를 기준으로 대안 탐색

# 4. 핵심 기능 명세

## F1. 출발지·목적지 및 보행 속도 설정

### 목적

경로 탐색과 막차 역산에 필요한 사용자 정보를 입력받는다.

### 출발지

브라우저 Geolocation API를 이용해 사용자의 현재 위치를 요청한다.

위치 권한이 허용된 경우 현재 위치를 출발지로 자동 설정한다.

사용자는 위치 권한을 허용한 경우에도 직접 검색 방식으로 전환할 수 있다.

위치 권한이 거부되거나 위치 탐색에 실패한 경우 출발지 검색을 통해 직접 장소를 설정한다.

### 목적지

카카오 장소 검색 API를 활용해 다음 정보를 검색할 수 있다.

- 역명
- 장소명
- 주소

검색 결과 중 하나를 선택하면 해당 장소의 위치 좌표를 저장한다.

### 보행 속도

사용자는 다음 네 가지 중 하나를 선택할 수 있다.

| 설정 | 도보시간 보정계수 |
|---|---:|
| 느림 | 1.2 |
| 보통 | 1.0 |
| 빠름 | 0.8 |
| 맞춤형 | 기본 1.0 또는 개인 배율 |

느림·보통·빠름 선택값은 실제 막차 역산 과정에서 도보시간에 반영된다.

현재 MVP에서 맞춤형을 선택한 경우 실제 GPS 기록을 자동 학습하지는 않으며, 별도의 개인 배율이 없는 경우 보통 속도인 1.0배로 계산한다.

GPS 이동 데이터를 누적하여 사용자의 실제 보행 속도를 자동 계산하는 기능은 향후 확장 기능이다.

### 데이터 저장

사용자의 보행 속도 설정은 브라우저 `localStorage`에 저장하여 다음 이용 시에도 유지한다.
